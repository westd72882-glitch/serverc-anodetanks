# Деплой сервера на Render — пошагово

## Что это

Сервер для игры: аккаунты (регистрация/вход) и вся экономика (покупка/продажа
танков, рулетка, кейсы, Battle Pass) — всё считается и проверяется здесь, а
не на телефоне игрока, чтобы это нельзя было взломать.

## Шаг 1 — создать базу данных на Render

1. Зайти на render.com, зарегистрироваться/войти (можно через GitHub).
2. Нажать **New +** → **PostgreSQL**.
3. Имя (любое, например `tank-game-db`), регион — любой ближайший.
   План — **Free**.
4. Нажать **Create Database**. Подождать пару минут, пока база создастся.
5. На странице базы найти поле **Internal Database URL** (не External) —
   скопировать это значение, оно понадобится на шаге 3. Выглядит как
   `postgres://user:password@host/dbname`.

## Шаг 2 — залить код на GitHub

Render разворачивает сервер из GitHub-репозитория. Если ещё нет
репозитория для этого сервера:

1. Создать новый репозиторий на github.com (например `tank-game-server`).
2. Загрузить в него содержимое папки `server/` (всё, что внутри — `src/`,
   `package.json`, `tsconfig.json` и т.д.), не саму папку `server` целиком.

## Шаг 3 — создать Web Service на Render

1. **New +** → **Web Service**.
2. Подключить тот GitHub-репозиторий, куда залили код.
3. Настройки:
   - **Region**: тот же, что у базы данных (для скорости)
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm run migrate && npm start`
     (`npm run migrate` создаёт таблицы в базе при первом запуске; на
     последующих запусках просто ничего не делает, если таблицы уже есть)
   - **Plan**: Free
4. Ниже, в разделе **Environment Variables**, добавить:
   - `DATABASE_URL` = то значение, что скопировали на шаге 1
   - `JWT_SECRET` = любая длинная случайная строка (например, придумать
     30+ случайных символов — это секрет для подписи токенов входа)
   - `SELF_URL` = оставить пустым пока (заполним после первого деплоя,
     когда узнаем итоговый адрес сервиса)
5. Нажать **Create Web Service**. Начнётся сборка — займёт несколько минут.

## Шаг 4 — заполнить SELF_URL

1. Когда сервис соберётся и запустится, Render покажет его адрес наверху
   страницы, вида `https://tank-game-server-xxxx.onrender.com`.
2. Скопировать этот адрес, зайти в **Environment** (левое меню сервиса),
   вставить его в переменную `SELF_URL`.
3. Сохранить — сервис перезапустится сам.

Это нужно, чтобы сервер сам себя "пинговал" каждые 30 секунд и не засыпал
на бесплатном тарифе.

## Шаг 5 — проверить, что всё работает

Открыть в браузере `https://ваш-адрес.onrender.com/health` — должно
показать что-то вроде `{"ok":true,"time":"..."}`. Если видите это —
сервер работает.

## Что дальше

Дальше нужно подключить сам C++ клиент игры к этому серверу (адрес
`https://ваш-адрес.onrender.com` вписывается в конфиг клиента) — это
отдельный шаг, ещё не сделан.

## Если что-то пошло не так

- Вкладка **Logs** в Render показывает, что происходит при старте/ошибках.
- Самая частая проблема — не тот `DATABASE_URL` (перепутали Internal/
  External, или скопировали не до конца).
